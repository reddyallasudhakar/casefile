# F2: document-type classification

**Question.** After fine-tuning, can a 0.5B model running on a laptop match a frontier
model at classifying Indian health-insurance claim pages into 10 document types?

## Success bar (set 2026-10-23, before any results)

The fine-tuned **Qwen2.5-0.5B-Instruct matches or beats Gemini Flash** on the test set:

- **Primary:** fine-tuned Qwen's accuracy ≥ Gemini Flash's accuracy on the same 124 test
  pages, with the same input (clean page text).
- **Reported alongside:** a paired McNemar test on the pages where the two models disagree,
  since one page is worth 0.8 points at this test-set size. If Qwen's accuracy is lower but
  the difference is not significant, the result is reported as "statistically
  indistinguishable", not as a pass.
- Macro-F1 and the invalid-output rate are reported for every model but don't decide
  the pass/fail.

## Test set

`bench/splits.json` (split draw #0): 47 cases, 124 pages, 10–14 pages per document type.
Split by case, so no test page shares a patient, hospital or amounts with training data.
The test set is never used for training or prompt tuning.

here. Gemini used ~1,100 input + 126 output/thinking tokens per page; its cost is estimated
from typical Flash list prices, not billed figures.

### What the baselines show

- **Untrained Qwen collapses onto two labels.** Almost every page is called `policy_schedule`
  or `health_card`; it loses even to keyword rules.
- **Few-shot examples didn't help** (25.8% vs 27.4%, well within noise). One 300-character
  example per type is not enough for a 0.5B model to learn ten categories in context.
- **Free generation goes semantically right but in the wrong format**: its invalid answers
  were `claim_repudiation_letter` (for rejection letters), `claim_query_letter` and `claim_form`.
  The model partly *understands* the pages; it doesn't know our label set. That's exactly what
  fine-tuning should fix.
- **Gemini at 100% is a warning about the test set, not just praise for Gemini.** Gemini
  wrote these pages, and many name their type in the title. Before reading too much into
  "match or beat Gemini", the comparison needs a harder, less circular test: OCR'd text from
  the degraded images, pages written by a different model, or real pages.
